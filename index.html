GC + DAQ 안정구간 자동 병합

Test station DAQ 로그와 GC raw data(Excel/CSV)의 시간을 맞춰 안정구간을 자동 탐지하고, 구간별로 색을 구분해 해당 구간의 GC 데이터를 정리합니다.
① 파일 넣기
DAQ 로그 (test station) Time_day, Time_hour + SV/PV 컬럼 CSV
여러 날짜 파일 동시 선택 가능
GC raw data Compound별 Area 표 + injection schedule(Inj.Date)
Excel(.xlsx) / CSV
② Reactor / 컬럼 매핑
파일마다 컬럼명이 다를 수 있어 직접 수정 가능합니다. Reactor를 바꾸면 기본값으로 자동 교체됩니다.
③ 볼 가스(성분) 선택
GC 파일에서 인식된 성분 목록입니다. Reactor를 바꾸면 해당 GC Signal의 성분이 기본으로 체크됩니다. 필요하면 자유롭게 추가/해제하세요.
④ 안정구간 자동탐지 설정
최근 window 구간에서 Furnace(설정온도)의 변동폭이 허용치 이내(=램프가 끝나고 유지 중)이고, TC(실측온도)가 Furnace 대비 허용오차 이내이며, NH3 PV(실측유량)의 표준편차가 허용오차 이내인 지점들을 안정 상태로 판정합니다. 이 조건이 동시에 유지되는 연속 구간을 하나의 안정구간으로 묶습니다. 온도 램프 도중이나 워밍업 구간은 자동으로 제외됩니다.
